# 智聊 · 单文件 AI 对话客户端

一个 **HTML 文件** 就是一个完整的多用户 AI 聊天软件：流式输出、KaTeX 数学公式、聊天记录本地加密、每人独立额度与限速、手机端适配。后端直接用智谱 GLM。

```
ai-chat.html            ← 双击就能用的全部（无构建、无依赖安装）
tools/build-key.mjs     ← 换/加密 API Key 的注入器
worker/cloudflare-worker.js  ← 可选：真正保证 Key 不外泄的中转（Cloudflare）
worker/node-proxy.mjs        ← 可选：本机/局域网中转（零依赖 Node）
```

## 1. 马上开始

1. 双击 `ai-chat.html`（Chrome / Edge / Safari 都行，不需要装任何东西、不需要起服务）。
2. 开场动画播完后点「注册」，输入用户名 + 密码（≥6 位）。**这个密码就是你的聊天记录加密密钥，忘了就真的找不回来了。**
3. 直接开聊。数学公式用 `$...$` 或 `$$...$$` 写，例如 `$$x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}$$`。

> 想放到手机上用：把 `ai-chat.html` 传到手机（微信/AirDrop/网盘），用手机浏览器打开即可；也可以丢进任意静态托管（GitHub Pages、Vercel、对象存储）得到一个网址。

## 3. 关于 API Key 的安全（请务必读完）

你要求「Key 不能随便被看见」。这里给出**诚实的结论**：

- 本文件里的 Key 是 **AES-GCM-256 加密**后写入的，口令被拆成 4 段、每段用不同掩码 XOR 打散，运行时才在内存里拼回去。所以：
  - 直接 `Ctrl+U` 看源码、搜 `cf8d` 或搜 `sk-`，**搜不到**；
  - 复制这个 HTML 文件给人，对方也拿不到明文 Key；
  - 用 `tools/build-key.mjs --verify` 需要自己实现同样的解密流程才能还原。
- **但是**：纯前端的加密，解密所需的一切都在文件里。会逆向的人最终一定能还原出 Key —— 这不是实现问题，而是「浏览器必须能解密才能用」的物理限制。
- 所以 **Key 值多少钱，就配多少防护**：
  - 只是自己/朋友几个人用 → 现状足够，建议定期换 Key（见下）。
  - 要发给陌生人、或者挂到公网上 → **请用方案 B**（第 5 节），Key 完全不出现在 HTML 里，并能在服务端做真正的限速。
- 另外：你这个 Key 已经在聊天记录里明文出现过一次，**建议去 [智谱开放平台](https://open.bigmodel.cn/) 重置一次**，再用下面的命令把新 Key 注入进来。

### 换 Key（30 秒）

```bash
node tools/build-key.mjs --key "新的智谱Key"        # 写进 ai-chat.html
node tools/build-key.mjs --verify                   # 校验能否解开
```

也可以不改文件：进管理面板 →「更换 API Key」，新 Key 会用同样的 AES-GCM 加密后存在本机 `localStorage`，且**优先级高于**文件内置的 Key。

## 4. 管理面板

侧栏左上角的 **Logo 连点 5 次**，或在地址后加 `#admin`。
默认口令 `admin888`（**第一次进入会自动改成哈希存储，请立刻改掉**）。

可以改：每日额度、每分钟上限、接口地址、可选模型列表、更换 API Key、修改管理口令、代理模式地址。

## 5. 方案 B：让 Key 真正不外泄（可选但推荐）

用中转服务把 Key 从浏览器里彻底拿走：

**Cloudflare Worker（免费、免服务器）**

```bash
npm i -g wrangler && wrangler login
wrangler secret put ZHIPU_API_KEY      # 粘贴你的 Key
wrangler deploy                        # 得到 https://xxx.workers.dev
```

**或者零依赖 Node（本机 / 局域网 / 自己的服务器）**

```bash
ZHIPU_API_KEY=你的Key node worker/node-proxy.mjs
# 输出：http://localhost:8787/api/chat
```

然后把地址填进管理面板 →「代理模式地址」。
之后浏览器只跟你的中转说话，HTML 文件里不再需要任何 Key；中转还自带每 IP 的服务端限速（默认 5 次/分钟、200 次/天）。

## 6. 各用户的额度与限速存在哪

- 计数在 `localStorage`（键 `zc.v1.usage.<用户ID>`），按用户独立。
- ⚠️ **诚实提醒**：纯前端计数只是「防误刷」，懂行的人清一下浏览器存储就能重置。要防恶意刷，必须用第 5 节的代理模式，把限速放到服务端。

## 7. 数据都存在哪（全部在这台设备上，不上传）

| 键 | 内容 | 是否加密 |
|---|---|---|
| `zc.v1.users` | 账号列表（用户名、盐、密码校验哈希） | 哈希，不含密码 |
| `zc.v1.vault.<用户ID>` | 该用户的全部对话与设置 | ✅ AES-GCM-256 |
| `zc.v1.usage.<用户ID>` | 今日次数、每分钟时间戳 | 否（仅计数） |
| `zc.v1.cfg` | 设备级配置（额度、模型、接口、代理地址） | 否 |
| `zc.v1.key` | 管理面板里覆盖的 API Key | ✅ AES-GCM-256 |
| `zc.v1.admin` | 管理口令的 PBKDF2 哈希 | 哈希 |
| `sessionStorage: zc.v1.unlock` | 勾选「刷新后保持登录」时的会话密钥 | 关闭标签页即消失 |

密钥派生：`PBKDF2-SHA256`，210000 轮，认证盐与保险箱盐分开。
**忘记密码 = 数据无法恢复**（这是加密的代价，不是 bug）。想留底就用设置里的「导出聊天记录」（导出的是明文 JSON，自己放好）。

## 8. 常见问题

| 现象 | 原因与处理 |
|---|---|
| `模型当前访问量过大（1305）` | 智谱官方繁忙，客户端会自动降级到列表里的下一个模型 |
| `账户余额不足（1113）` | Key 对应账号没有余额；免费模型（`glm-4-flash`、`glm-4.5-flash`、`glm-4.7-flash`）不需要余额 |
| 公式显示成原始文本 | KaTeX 的 CDN 被网络挡住了，换个网络或忽略即可（正文与公式仍可读） |
| `网络请求失败` | 断网、被安全软件拦截，或该环境不允许跨域 |
| 提示「本机存储已满」 | `localStorage` 约 5MB 上限，删掉一些旧对话或导出后清理 |
| 手机上回车不发送 | 故意设计（手机上回车换行，点右下角圆形按钮发送） |

## 9. 开发者备注

- 单文件、无构建、无框架、无外部依赖（除 KaTeX 走 CDN）；所有代码用 ES5 语法写，兼容到很老的手机浏览器。
- 视觉规范集中在 `<style>` 顶部的设计令牌里（`--ds-blue` 是品牌主色，`html[data-theme="light"]` / `[data-theme="dark"]` 两套变量），改配色只动那一段即可。
- 新增/修改功能后建议至少验证：注册登录 → 发消息流式返回 → 公式渲染 → 连发 6 条触发限速 → 建第二个账号确认隔离 → 手机宽度下抽屉与布局。
- 中转服务只是转发，不解析内容；`stream: true` 时按块透传，保证流式不掉帧。
